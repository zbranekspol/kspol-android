základu `Kspol_STABLE_RESET_v8_BASELINE.apk`. Kód z v7 nebyl použit.

- logo +K spol.
- šest hlavních kategorií
- tlačítko ZOBRAZIT VŠE

vícepoložková poptávka s možností ODEBRAT.
